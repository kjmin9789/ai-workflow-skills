# Purchase Psychology UX

Use this skill to turn buying psychology into practical UX decisions. Focus on screen structure, message placement, option design, and trust, not academic psychology explanations.

## Workflow

1. Identify the user decision: sign up, buy, choose a plan, continue, return, save, upgrade, or not leave.
2. Identify the friction: uncertainty, price resistance, low urgency, weak perceived value, lack of trust, too many options, or weak ownership.
3. Choose only the trigger that matches the friction.
4. Place the message near the decision point: CTA, pricing comparison, checkout, exit modal, trial end, product detail, onboarding, or retention notification.
5. Check trust: use only true, specific, and verifiable claims.

Read [examples.md](references/examples.md) when concrete wording patterns or before/after examples are needed.

## Trigger Guide

| Trigger | Use When | UX Move | Avoid |
| --- | --- | --- | --- |
| Loss aversion | The user may lose progress, a real benefit, saved work, a coupon, availability, or time. | State the specific thing that will be lost if the user does not act. | Fake danger, vague fear, exaggerated warnings. |
| Anchoring | The user needs to judge price, value, discount, or plan level. | Show a clear reference point before the target price or option. | Fake list prices or confusing price math. |
| Social proof | The user is uncertain whether the choice is credible or safe. | Show real behavior data: reviews, usage, purchases, adoption, repeat rate, or named cases. | Inflated numbers, unverifiable popularity claims. |
| Scarcity | The opportunity is genuinely limited by stock, time, season, seats, or eligibility. | Show the real limit and deadline close to the CTA. | Repeating fake scarcity or endless countdowns. |
| Reciprocity | The service gives value before asking for action. | Make the received value visible and connect it to the next step. | Guilt-tripping the user. |
| Decoy effect | The user must compare multiple plans or packages. | Add or adjust a comparison option so the intended choice is easier to evaluate. | Manipulative bundles or deliberately confusing options. |
| Endowment effect | The user can experience the product before purchase or commitment. | Let the user try, preview, personalize, save, or configure before asking them to commit. | Making cancellation or return feel hidden or punitive. |

## Writing Rules

- Prefer concrete facts over broad persuasion.
- Write the consequence, not the emotion you want the user to feel.
- Put the trigger near the action it supports.
- Use one primary trigger per decision moment.
- Keep the user's control visible: cancel, compare, edit, return, or learn more.
- Remove the trigger if it would reduce trust when read literally.

## Output Checklist

When applying this skill, provide:

- The selected trigger and why it fits the user friction.
- The recommended placement in the screen or flow.
- The revised UX copy or option structure.
- A trust check explaining what must be true for the message to be acceptable.
