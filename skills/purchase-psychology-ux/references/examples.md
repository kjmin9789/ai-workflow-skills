# Examples

Use these examples only when wording or structure patterns are needed. Adapt tone to the product and keep claims factual.

## Loss Aversion

Use for real loss: saved work, streaks, coupons, availability, trial access, or booking windows.

- Weak: `지금 신청하면 혜택을 받을 수 있어요.`
- Better: `오늘이 지나면 이 쿠폰은 사라져요.`
- Weak: `저장하면 나중에 다시 볼 수 있어요.`
- Better: `저장하지 않으면 작성 중인 내용이 사라져요.`
- Placement: exit modal, save prompt, coupon reminder, trial end, checkout.

## Anchoring

Use when users need a reference point for price or value.

- Weak: `월 29,000원`
- Better: `월 49,000원 상당의 기능을 월 29,000원에 이용할 수 있어요.`
- Weak: `20% 할인`
- Better: `정가 120,000원 → 오늘 결제 시 96,000원`
- Placement: pricing page, product detail, upgrade modal, estimate screen.

## Social Proof

Use when users need confidence that others have chosen or trusted the option.

- Weak: `많은 사용자가 선택했어요.`
- Better: `이번 주 1,240명이 구매했어요.`
- Weak: `만족도가 높아요.`
- Better: `리뷰 3,482개, 평균 평점 4.8점`
- Placement: product cards, plan cards, checkout reassurance, onboarding, B2B case section.

## Scarcity

Use only for genuine limits.

- Weak: `서두르세요.`
- Better: `남은 좌석 4개`
- Weak: `곧 종료됩니다.`
- Better: `7월 10일 23:59까지 신청할 수 있어요.`
- Placement: CTA 근처, booking flow, event signup, limited stock product page.

## Reciprocity

Use after the service has already given something useful.

- Weak: `가입해 주세요.`
- Better: `무료 진단 결과를 저장하려면 계정을 만들어 주세요.`
- Weak: `배송비 무료`
- Better: `이번 주문의 배송비 3,000원은 저희가 부담했어요.`
- Placement: free report, sample, trial, fee waiver, customer support follow-up.

## Decoy Effect

Use in plan or package comparison.

- Structure: `Basic` / `Standard` / `Premium`
- Move: make the target plan visibly better value than the lower plan, not merely more expensive.
- Pattern: `월 9,900원 기본형` / `월 14,900원 추천형: 핵심 기능 포함` / `월 29,900원 전문가형`
- Placement: pricing table, package selector, subscription upgrade.

## Endowment Effect

Use when users can feel ownership before purchase.

- Weak: `프리미엄을 구매하세요.`
- Better: `내 템플릿으로 저장한 뒤 프리미엄 기능을 적용해 보세요.`
- Weak: `안경을 구매하세요.`
- Better: `내 얼굴에 먼저 착용해 보고 결정하세요.`
- Placement: preview, trial, demo account, customization, cart save, virtual try-on.

## Quick Mapping

| Friction | Trigger |
| --- | --- |
| "나중에 할게요" | Loss aversion or scarcity |
| "비싼 것 같아요" | Anchoring or decoy effect |
| "믿어도 되나요?" | Social proof |
| "왜 지금 해야 하죠?" | Scarcity or loss aversion |
| "아직 내게 필요한지 모르겠어요" | Endowment effect |
| "받은 가치를 못 느껴요" | Reciprocity |
